# ノイシュヴァンシュタイン城さんぽ

ドイツ・バイエルン州シュヴァンガウ、ルートヴィヒ2世の白亜の城を、スマホで歩いて巡る3D散策。
世界さんぽシリーズ（ヴェルサイユ宮殿さんぽ・ウィンザー城さんぽ）と同じ操作系（three.js r128・単一HTML）。

- 城：門の館（赤い煉瓦のトーアバウ）、下の中庭、上の中庭、騎士の館、四角い塔、婦人の館（ケメナーテ）、本館パラス、北の大階段の塔
- パラスの中：3階＝玉座の間（瑠璃と斑岩の柱・星空の天井・王冠のシャンデリア・200万個の石のモザイク床・玉座のない壇）、食堂、王の寝室、王の礼拝堂、着替えの間、居間（白鳥の間）、洞窟、冬の庭、書斎、玉座の間のバルコニー／4階＝歌人の間（パルジファルの壁画・舞台）、玉座の間の回廊、ヤシの柱と竜
- らせん階段：階段の間の北の戸口で「上る／下りる」（中庭の階⇄3階⇄4階）。4階の歌人の間で登城の印
- まわり：城への坂道、マリエン橋とペラート渓谷の滝、ホーエンシュヴァンガウ村（チケットセンター・馬車）、ホーエンシュヴァンガウ城、アルプ湖、聖コロマン教会と野原の牛
- とき：1886年 王の時代（婦人の館は工事中・蒸気クレーン・王の金の馬車・夜は窓という窓に灯り）／現在（2026年）／夢の完成図（高さ約90mの大塔と城の礼拝堂）
- 時刻：朝・昼・夕・夜（現在と完成図は城の投光）、季節：夏・秋・冬（雪・凍った湖）、天気：晴れ・霧（谷の雲海）
- 見どころ札集め（全34か所・歩いて訪れたときだけ。localStorage `neuschwanstein_fuda`）、登城の印（`neuschwanstein_seal`）、写真モード、道案内（光の矢印。らせん階段もまたぐ）、合成音（山の風・滝・玉座の間の和音・歌人の間のハープ・洞窟のしずく・牛の鈴・工事の音）

建物や村は写真や資料をもとにした簡略な再現で、距離や部屋の大きさは歩きやすく整えています。方角はおおむね実際どおり（北がシュヴァンガウの野原、南がアルプス）。「夢の完成図」は王の計画をもとにした想像です。
